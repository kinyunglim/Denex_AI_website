# 【客人名稱】網站及後台使用說明

> 範本：交付前將【】內容換成客人資料，刪走用唔著的模組章節。

## 1. 重要資料
| 項目 | 內容 |
|---|---|
| 網站 | 【https://www.example.com】 |
| 後台 | 【https://www.example.com/admin】 |
| 你的登入電郵 | 【owner@example.com】 |
| 技術支援 | 【你公司名稱 · WhatsApp · 電郵】 |
| 月費包括 | 【寄存、資料庫、備份、保安更新、每月 N 次內容修改】 |

## 2. 登入後台
1. 開 【/admin】，輸入電郵同密碼。
2. 系統會寄 6 位數驗證碼到你的電郵，5 分鐘內輸入。
3. 右下角可以切換「中文 / English」。

## 3. 客戶（CRM）
- 網站查詢、網上預約、產品查詢都會**自動建立客戶**；同一個電話或電郵只會有一個客戶。
- 按客戶名可以：改資料、加標籤（例如 VIP）、寫備註、睇所有記錄（查詢、預約、收款）。
- 「查詢」頁：處理完一條查詢記得按「標記已處理」。

## 4. 匯入 / 匯出 Excel（只限擁有人）
1. 準備 Excel：第一行係欄位名稱（姓名、電話、電郵、標籤…）。
2. 後台 →「匯入匯出」→ 上載 → 檢查欄位對應 → 按「確認匯入」。
3. 有問題的行會列出行號同原因，改好 Excel 再匯入一次即可（唔會重複建立客戶）。
4. 「匯出客戶 Excel」可以隨時下載全部客戶。

## 5. 預約【如有】
- 「預約設定」：新增服務（時長、價錢）、員工同每週工作時間、休假。
- 工作時間格式：每行一段，例如 `1 10:00-19:00`（1 = 星期一，0 = 星期日）。
- 「預約」：一週日曆；可以標記完成 ✓、缺席或取消（取消後時段會自動開放）。
- 客人網上預約後，你同客人都會收到確認電郵。

## 6. 收款及收據【如有】（只限擁有人）
- 客戶頁 →「記錄收款」：輸入金額同付款方式，系統自動編收據號碼。
- 「收款」頁可以按月份睇總數，按收據號碼可以列印中英文收據。
- 【Stripe】客戶頁 →「建立付款連結」，將連結 WhatsApp 畀客人；付款後會自動入賬。

## 7. 產品目錄【如有】
- 「產品」：新增產品名稱（三語）、描述、分類、圖片網址、規格（每行 `名稱: 內容`）。
- 取消勾選「啟用」可以暫時隱藏產品。

## 8. 團隊（只限擁有人）
- 「團隊」→ 新增管理員：「擁有人」有全部權限；「員工」睇唔到收款、匯出同團隊設定。
- 員工離職：取消勾選「啟用」即時停用。

## 9. 常見問題
- **收唔到驗證碼？** 檢查垃圾郵件；仍然冇就聯絡技術支援。
- **想改網站文字 / 相片？** WhatsApp 【技術支援】，月費包 【N】 次修改。
- **資料安全？** 資料存放於 MongoDB Atlas（【香港 / 新加坡】），每日自動備份。
